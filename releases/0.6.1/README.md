# OmniTerm 0.6.1

This is the latest OmniTerm distribution.

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.6.1/OmniTerm-0.6.1.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.6.1/OmniTerm-0.6.1.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.6.1/OmniTerm-0.6.1-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#061---2026-11-25).

These macOS arm64 artifacts were built from source commit `0e44620`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were reused from earlier
source builds rather than rebuilt for this release, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
