# OmniTerm 0.6.2

This release is superseded by [OmniTerm 0.7.0](../0.7.0/README.md).

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.6.2/OmniTerm-0.6.2.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.6.2/OmniTerm-0.6.2.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.6.2/OmniTerm-0.6.2-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#062---2026-11-25).

These macOS arm64 artifacts were built from source commit `a9b2736`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were reused from earlier
source builds rather than rebuilt for this release, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
