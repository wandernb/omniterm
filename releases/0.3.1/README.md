# OmniTerm 0.3.1

This is the latest OmniTerm distribution.

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.3.1/OmniTerm-0.3.1.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.3.1/OmniTerm-0.3.1.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.3.1/OmniTerm-0.3.1-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#031---2026-11-01).

These macOS arm64 artifacts were built from source commit `7855784`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were rebuilt from
source, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
