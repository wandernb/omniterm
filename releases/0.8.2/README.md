# OmniTerm 0.8.2

This release is superseded by [OmniTerm 0.8.3](../0.8.3/README.md).

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.8.2/OmniTerm-0.8.2.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.8.2/OmniTerm-0.8.2.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.8.2/OmniTerm-0.8.2-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#082---2026-11-26).

These macOS arm64 artifacts were built from source commit `5cd7511`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were reused from earlier
source builds rather than rebuilt for this release, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
