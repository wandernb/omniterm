# OmniTerm 0.11.0

This is the latest OmniTerm distribution.

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.11.0/OmniTerm-0.11.0.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.11.0/OmniTerm-0.11.0.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.11.0/OmniTerm-0.11.0-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#0110---2026-11-28).

These macOS arm64 artifacts were built from source commit `a284537`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were reused from earlier
source builds rather than rebuilt for this release, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
