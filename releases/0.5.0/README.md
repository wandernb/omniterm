# OmniTerm 0.5.0

This release is superseded by [OmniTerm 0.6.0](../0.6.0/README.md).

- [Download the DMG](https://github.com/wandernb/omniterm/releases/download/v0.5.0/OmniTerm-0.5.0.dmg)
- [Download the ZIP](https://github.com/wandernb/omniterm/releases/download/v0.5.0/OmniTerm-0.5.0.zip)
- [Download the corresponding source](https://github.com/wandernb/omniterm/releases/download/v0.5.0/OmniTerm-0.5.0-source.tar.gz)
- Verify the DMG and ZIP with `SHA256SUMS` in this directory.
- Read the [changelog](../../CHANGELOG.md#050---2026-11-25).

These macOS arm64 artifacts were built from source commit `f504f86`, ad-hoc
signed, and are not Apple-notarized. Native dependencies were reused from earlier
source builds rather than rebuilt for this release, except `librailroad_dsl` and the generated `SFSymbolEnum`, which are
upstream's. The DMG contains OmniTerm, the installer, the changelog, the complete
GPL license, and third-party notices.
