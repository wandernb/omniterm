# Offline outcome review prototype

Open `outcome-review.html` directly from this folder in a browser (`file://`);
no server, network connection, scripts or dependencies are required.
On a narrow viewport, Tab to the evidence table and use Left/Right to scroll.

The three entirely fictional outcomes separate human acceptance, rejection and
deferral from identical provider completion, notice delivery and read states.
All evidence, counts, decision notes and the existing PR reference are synthetic.
Unknown cost and unavailable evidence stay explicit.

Palette and system monospace stack come from `../styles.css`; styles are inlined
so the fixture is self-contained. The layout follows the scoped preparation
brief; it reads no application data and has no native integration or persistence.
There are no published navigation links to this prototype.

Gaps: browser rendering, narrow-screen scrolling, keyboard behavior and assistive
technology behavior have not been verified. This fixture does not establish
product usability, human acceptance of the design, adoption or outcome quality.
